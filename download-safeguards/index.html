Download Safeguards

What we accept when submission documents are downloadable.

Overview

The program focuses on protecting the initial submission package, where unauthorized use most often occurs. View-only access meets this requirement. Downloadable files are permitted, but once downloaded they are stored locally and can potentially be sent outside company systems, so a safeguard is needed.

Guidelines apply to deal-processing roles (e.g. underwriters, sales).

Acceptable Safeguards

This item can clear upon receipt of one of the following:

  1. Change document access to view-only.
  2. Documents watermarked with the company name or logo before reaching the system of record, or at the time of download. Watermarking is accepted as a reasonable deterrent against misuse.
  3. If documents must remain downloadable, browser restrictions that block access to personal email and cloud storage domains, along with device controls that prevent file transfers through USB.
  4. Other: another safeguard or approach that meets the intent of the requirement. We’re happy to review alternatives or schedule a brief call to discuss practical options.

Methods

Common ways organizations put browser and device controls in place:

  • Managed devices: Company-owned computers configured with security rules that control what users can access, download, or move. Examples may include Group Policy (GPO) on Windows devices.
  • Virtual/remote workspaces: A controlled company desktop or workspace that employees access remotely. Files and applications stay inside that environment rather than on the employee’s personal device. Examples include Windows 365, Azure Virtual Desktop, and Amazon WorkSpaces.
  • Endpoint management: Software used to centrally apply and enforce security settings on employee devices, such as blocking USB, restricting apps, or controlling file transfers. Examples include Microsoft Intune and Jamf.
  • Enterprise browser controls: A managed browser that limits what users can do inside the browser, such as blocking personal email, cloud storage, downloads, or copy/paste. Examples include Island and Prisma.
